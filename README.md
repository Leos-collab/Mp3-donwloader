# Baixador de MP3 do YouTube

Este é um script em Python que baixa o áudio de qualquer vídeo do YouTube e converte automaticamente para o formato MP3 (na melhor qualidade disponível).

## 🚀 Como usar

Sempre que você quiser baixar uma música nova, siga os passos abaixo:

1. **Abra o Terminal** (Pressione a tecla `Windows`, digite `PowerShell` ou `Prompt de Comando` e dê Enter).
2. **Navegue até esta pasta** (se você não estiver nela, digite o comando abaixo):
   ```powershell
   cd "Desktop\Mp3 donwloades"
   ```
3. **Execute o script** com o Python:
   ```powershell
   python Teste.py
   ```
4. **Cole o link** do vídeo do YouTube quando for solicitado e dê `Enter`.

🎉 Pronto! O script vai baixar o vídeo, converter e salvar o arquivo `.mp3` automaticamente **dentro desta mesma pasta**.

---

## 🛠️ O que já está instalado (Não precisa fazer de novo)
O seu computador já foi configurado com tudo que é necessário para este script funcionar:
- **Python**: A linguagem de programação usada para rodar o código.
- **FFmpeg**: O conversor de áudio "invisível" que transforma o download em MP3.
- **yt-dlp**: A biblioteca mágica (instalada via `pip`) que faz a conexão com o YouTube para baixar o arquivo.
